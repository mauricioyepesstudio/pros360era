# Perfiles profesionales (agency-agents)

Perfiles de oficio tomados de https://github.com/msitarzewski/agency-agents (commit 8ae6164, licencia MIT, ver `LICENSE-agency-agents.txt`). Están en inglés y sin cambios.

Esta carpeta **no** está dentro de `.claude/agents/`, así que Claude Code no los carga como agentes sueltos. Cada agente de `.claude/agents/` tiene una sección "Perfil profesional (agency-agents)" que dice cuál leer. Las reglas del agente y de la empresa mandan sobre el perfil base.
