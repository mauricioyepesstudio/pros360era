# Propuestas gráficas privadas del planner

Cada propietario con sesión PROFESSIONAL/ADMIN y perfil propio obtiene PNGs locales, dentro de las sugerencias semanales existentes. La identidad se resuelve exclusivamente desde Supabase getUser y consultas de perfil/rol del usuario; el endpoint no admite propietario por parámetro. No requiere aprobación pública del profesional para usar sus herramientas privadas.

Imágenes 1080×1350 y1080×1920 con identidad de EVOLUSA, desde tokens de app/globals.css. Son composiciones tipográficas locales, no fotografía de IA ni logos propios verificados. La propuesta de reel es portada+guion, no video. Sin llamadas a proveedores pagos.

Selección guarda IDEA con URL de imagen privada, sin reemplazar planner. PNG previsualizado sin optimizador compartido; cacheprivate,no-store,VaryCookie. Se puede descargar. Publisher y constructores de solicitudes de Instagram/Facebook rechazan este endpoint privado, incluso con URL absoluta. Para publicar hay que descargar,revisar y adjuntar mediante el flujo existente con consentimiento; ese recorrido externo no queda verificado por esta entrega.

No se publican medios ni se envían correos. No añade credenciales,servicerole,tablas ni permisos. No garantiza cancelación de publicaciones anteriores ya iniciadas. El render privado es vivo: si cambia el nombre/categoría, la siguiente vista lo refleja; no equivale a archivo histórico inmutable.

Pruebas: parámetros desconocidos/duplicados,ausencia de sesión,aislamiento de contexto,caché,descarga,error cerrado,escape de perfil,PNG real,resoluciones,selecciónIDEA ydenegación publisher.
